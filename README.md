# Customer Segmentation using K-Means

## 📌 Overview

This project uses **K-Means Clustering** to group customers of a retail store based on their purchase behavior.

## 📊 Dataset

Mall Customer Dataset containing:

* CustomerID
* Gender
* Age
* Annual Income (k$)
* Spending Score (1–100)

## ⚙️ Method

* Selected features: **Annual Income** and **Spending Score**
* Used **Elbow Method** to find optimal clusters
* Applied **K-Means (K=5)** for segmentation

## 📈 Results

* Customers grouped into **5 clusters**
* Each cluster represents different spending patterns
* Visualized using scatter plots and centroids

## 🚀 How to Run

```bash
py kmeans_clustering.py
```

## 🧠 Conclusion

K-Means clustering helps businesses understand customer segments for better marketing and decision-making.
